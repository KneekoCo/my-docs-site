How to Provision a SharePoint Backend for a Recipe + Shopping List Power App

Use this guide to teach beginners how to stand up a SharePoint backend using PowerShell 7+ (pwsh) and PnP.PowerShell. It mirrors the style of the Notion Task Tracker page—step‑by‑step, visuals, and short tips—while showcasing clean, portfolio‑ready automation.

What You’ll Build​

  • Two SharePoint lists: Recipes, RecipeIngredients
  • Core fields: titles, yield, instructions, notes; ingredients, quantities, sections, flags, numeric recipe link
  • Three views on RecipeIngredients: All Ingredients (default), Need to Buy, Have at Home
  • Idempotent scripts you can re‑run safely
Assumptions

You’ll run PowerShell 7+ and install PnP.PowerShell. Authentication uses a public client Entra ID app (no client secret).

Step-by-Step Instructions​

Step 1: Create a One‑Time Entra ID App (for Interactive Login)​

  1. Open Entra ID → App registrations → New registration Name: PnP Interactive · Accounts: Single tenant · Redirect URI: Mobile & desktop → http://localhost


  1. App → Authentication → Allow public client flows → Yes Confirm http://localhost exists under Mobile & desktop applications.


  1. App → API permissions → Add a permission

    • Microsoft Graph → Delegated → User.Read, openid, offline_access
    • SharePoint → Delegated → AllSites.FullControl Click Grant admin consent.


  1. Save your values Tenant domain (e.g., contoso.onmicrosoft.com) and Client ID (GUID).


Mind the Tenant

Use your onmicrosoft.com domain for $Tenant (e.g., contoso.onmicrosoft.com), not a sharepoint.com URL.

Step 2: Verify PowerShell 7+​

  1. Open PowerShell 7 (black icon) or run pwsh.
  2. Check the version:
$PSVersionTable.PSEdition   # expect Core
$PSVersionTable.PSVersion   # Major should be 7+
Common Error

If you see Windows PowerShell 5.1, install PowerShell 7 and re‑open pwsh.

Step 3: Install & Import PnP.PowerShell​

Install-Module PnP.PowerShell -Scope CurrentUser -Force
Import-Module PnP.PowerShell -Force
First‑time prompts

If asked to install the NuGet provider or trust PSGallery, answer Y.

Step 4: Connect to Your SharePoint Site​

# Clean any old session
Disconnect-PnPOnline -ClearPersistedLogin -ErrorAction SilentlyContinue

# TODO: replace placeholders
$SiteUrl  = "https://contoso.sharepoint.com/sites/RecipeApp"
$Tenant   = "contoso.onmicrosoft.com"
$ClientId = "00000000-0000-0000-0000-000000000000"

# Interactive login via your Entra app
Connect-PnPOnline -Url $SiteUrl -Tenant $Tenant -ClientId $ClientId -Interactive
Get-PnPWeb | Format-List Title,Url
Optional: Remember your Client ID
[Environment]::SetEnvironmentVariable('ENTRAID_CLIENT_ID','00000000-0000-0000-0000-000000000000',[EnvironmentVariableTarget]::User)
# New shells can now do: Connect-PnPOnline -Url $SiteUrl -Tenant $Tenant -Interactive

Step 5: Create Two Lists​

New-PnPList -Title "Recipes" -Template GenericList -OnQuickLaunch -ErrorAction SilentlyContinue
New-PnPList -Title "RecipeIngredients" -Template GenericList -OnQuickLaunch -ErrorAction SilentlyContinue
Get-PnPList -Identity "Recipes","RecipeIngredients" | Select Title,ItemCount | Format-Table
Idempotent

New-PnPList safely skips creation if the list already exists.

Step 6: Add Columns (Internal Names & Types)​

Use the snippets below. Replace DisplayName / InternalName / ListTitle.

Cheatsheet​

Text

Add-PnPField -List "<ListTitle>" -DisplayName "<DisplayName>" -InternalName "<InternalName>" -Type Text -AddToDefaultView

Note (plain)

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='Note' Name='<InternalName>' DisplayName='<DisplayName>' NumLines='10' RichText='FALSE' />"

Boolean

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='Boolean' Name='<InternalName>' DisplayName='<DisplayName>' Default='0' />"

Choice (single)

$choices = @('Produce','Meat','Dairy','Pantry','Bakery','Frozen','Other')
$xml = "<Field Type='Choice' Name='<InternalName>' DisplayName='<DisplayName>' Format='Dropdown'><CHOICES>" +
       (($choices | % {"<CHOICE>$_</CHOICE>"}) -join '') + "</CHOICES></Field>"
Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml $xml

Number

Add-PnPField -List "<ListTitle>" -DisplayName "<DisplayName>" -InternalName "<InternalName>" -Type Number
Internal names are immutable

Choose internal names carefully (no spaces). Display names can change later.

Apply to This Project​

# Recipes
Add-PnPField -List "Recipes" -DisplayName "Yield" -InternalName "Yield" -Type Text -ErrorAction SilentlyContinue
Add-PnPFieldFromXml -List "Recipes" -FieldXml "<Field Type='Note' Name='Instructions' DisplayName='Instructions' NumLines='10' RichText='FALSE' />"
Add-PnPFieldFromXml -List "Recipes" -FieldXml "<Field Type='Note' Name='Notes' DisplayName='Notes' NumLines='10' RichText='FALSE' />"

# RecipeIngredients
Add-PnPField -List "RecipeIngredients" -DisplayName "Ingredient Name" -InternalName "IngredientName" -Type Text -ErrorAction SilentlyContinue
Add-PnPField -List "RecipeIngredients" -DisplayName "Qty Display" -InternalName "QtyDisplay" -Type Text -ErrorAction SilentlyContinue
$choices = @('Produce','Meat','Dairy','Pantry','Bakery','Frozen','Other')
$xml = "<Field Type='Choice' Name='StoreSection' DisplayName='Store Section' Format='Dropdown'><CHOICES>" + (($choices | % {"<CHOICE>$_</CHOICE>"}) -join '') + "</CHOICES></Field>"
Add-PnPFieldFromXml -List "RecipeIngredients" -FieldXml $xml
Add-PnPFieldFromXml -List "RecipeIngredients" -FieldXml "<Field Type='Boolean' Name='HaveAtHome' DisplayName='Have At Home' Default='0' />"
Add-PnPFieldFromXml -List "RecipeIngredients" -FieldXml "<Field Type='Boolean' Name='Purchased' DisplayName='Purchased' Default='0' />"
Add-PnPField -List "RecipeIngredients" -DisplayName "RecipeId" -InternalName "RecipeId" -Type Number -ErrorAction SilentlyContinue

Step 7: Create Three Views (CAML)​

foreach ($v in @("All Ingredients","Need to Buy","Have at Home")) { try { Remove-PnPView -List "RecipeIngredients" -Identity $v -ErrorAction SilentlyContinue } catch {} }

$fields = @("LinkTitle","QtyDisplay","StoreSection","HaveAtHome","Purchased","RecipeId")

Add-PnPView -List "RecipeIngredients" -Title "All Ingredients" -Fields $fields | Out-Null
Set-PnPView -List "RecipeIngredients" -Identity "All Ingredients" -Values @{ Query = "<Query><OrderBy><FieldRef Name='StoreSection' /><FieldRef Name='IngredientName' /></OrderBy></Query>"; DefaultView=$true } | Out-Null

Add-PnPView -List "RecipeIngredients" -Title "Need to Buy" -Fields $fields | Out-Null
Set-PnPView -List "RecipeIngredients" -Identity "Need to Buy" -Values @{ Query = "<Query><Where><And><Eq><FieldRef Name='HaveAtHome' /><Value Type='Boolean'>0</Value></Eq><Eq><FieldRef Name='Purchased' /><Value Type='Boolean'>0</Value></Eq></And></Where><OrderBy><FieldRef Name='StoreSection' /><FieldRef Name='IngredientName' /></OrderBy></Query>" } | Out-Null

Add-PnPView -List "RecipeIngredients" -Title "Have at Home" -Fields $fields | Out-Null
Set-PnPView -List "RecipeIngredients" -Identity "Have at Home" -Values @{ Query = "<Query><Where><Eq><FieldRef Name='HaveAtHome' /><Value Type='Boolean'>1</Value></Eq></Where><OrderBy><FieldRef Name='StoreSection' /><FieldRef Name='IngredientName' /></OrderBy></Query>" } | Out-Null
CAML is picky

Copy the CAML exactly. A missing tag will break the view.

Step 8: Verify Your Work​

Get-PnPList -Identity "Recipes","RecipeIngredients" | Select Title,ItemCount | Format-Table
Get-PnPListItem -List "Recipes" -PageSize 50 | Select Id,Title | Format-Table
Get-PnPListItem -List "RecipeIngredients" -PageSize 50 | Select Id,Title,QtyDisplay,StoreSection,HaveAtHome,Purchased,RecipeId | Format-Table
Next: Bind in Power Apps

Add both lists as data sources. Gallery Items for a recipe: Filter(RecipeIngredients, RecipeId = varRecipeId). Use toggles to update Purchased and HaveAtHome.

Quick Copy/Paste Script​

Paste into pwsh, edit the TODOs, run end‑to‑end.

# QuickStart — end‑to‑end provisioning (interactive auth)
Disconnect-PnPOnline -ClearPersistedLogin -ErrorAction SilentlyContinue

# TODO: replace placeholders
$SiteUrl  = "https://contoso.sharepoint.com/sites/RecipeApp"
$Tenant   = "contoso.onmicrosoft.com"
$ClientId = "00000000-0000-0000-0000-000000000000"

if (-not (Get-Module -ListAvailable -Name PnP.PowerShell)) { Install-Module PnP.PowerShell -Scope CurrentUser -Force }
Import-Module PnP.PowerShell -Force
Connect-PnPOnline -Url $SiteUrl -Tenant $Tenant -ClientId $ClientId -Interactive

# Lists
foreach ($l in @("Recipes","RecipeIngredients")) {
  if (-not (Get-PnPList -Identity $l -ErrorAction SilentlyContinue)) {
    New-PnPList -Title $l -Template GenericList -OnQuickLaunch | Out-Null
  }
}

# Fields (Recipes)
Add-PnPField -List "Recipes" -DisplayName "Yield" -InternalName "Yield" -Type Text -ErrorAction SilentlyContinue
Add-PnPFieldFromXml -List "Recipes" -FieldXml "<Field Type='Note' Name='Instructions' DisplayName='Instructions' NumLines='10' RichText='FALSE' />"
Add-PnPFieldFromXml -List "Recipes" -FieldXml "<Field Type='Note' Name='Notes' DisplayName='Notes' NumLines='10' RichText='FALSE' />"

# Fields (RecipeIngredients)
Add-PnPField -List "RecipeIngredients" -DisplayName "Ingredient Name" -InternalName "IngredientName" -Type Text -ErrorAction SilentlyContinue
Add-PnPField -List "RecipeIngredients" -DisplayName "Qty Display" -InternalName "QtyDisplay" -Type Text -ErrorAction SilentlyContinue
$choices = @('Produce','Meat','Dairy','Pantry','Bakery','Frozen','Other')
$xml = "<Field Type='Choice' Name='StoreSection' DisplayName='Store Section' Format='Dropdown'><CHOICES>" + (($choices | % {"<CHOICE>$_</CHOICE>"}) -join '') + "</CHOICES></Field>"
Add-PnPFieldFromXml -List "RecipeIngredients" -FieldXml $xml
Add-PnPFieldFromXml -List "RecipeIngredients" -FieldXml "<Field Type='Boolean' Name='HaveAtHome' DisplayName='Have At Home' Default='0' />"
Add-PnPFieldFromXml -List "RecipeIngredients" -FieldXml "<Field Type='Boolean' Name='Purchased' DisplayName='Purchased' Default='0' />"
Add-PnPField -List "RecipeIngredients" -DisplayName "RecipeId" -InternalName "RecipeId" -Type Number -ErrorAction SilentlyContinue

# Views

Write-Host "Backend provisioned. Verify lists and views in your site." -ForegroundColor Green

Troubleshooting​

  • Please specify a valid client id → Add -ClientId <your-guid> and verify the value from App registrations.
  • Access denied → Use an account with Edit/Owner on the target site.
  • Install-Module not recognized → You’re in Windows PowerShell; open pwsh (PowerShell 7).
  • CAML errors → Copy CAML exactly; a single missing tag will fail the view.
