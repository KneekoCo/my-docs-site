SharePoint Recipes Backend (PnP.PowerShell)

Overview​

You will deploy two SharePoint lists that back a simple Recipe + Shopping List Power App. You’ll connect with Connect-PnPOnline, create or update lists, add fields, define views, and seed sample data. Everything is beginner‑friendly and copy/paste‑ready.

Prerequisites​

  • PowerShell 7+ (pwsh).
  • PnP.PowerShell module.
  • A SharePoint site URL where you have permission to create lists.
  • Your tenant uses modern SharePoint Online.

Note: Replace placeholders like <contoso> and <your-site> before running.

What You’ll Deploy​

Lists

  • Recipes: Title, Yield, Instructions, Notes
  • RecipeIngredients: Ingredient Name, Qty Display, Store Section, Have At Home, Purchased, RecipeId (number link to Recipes)

Views (RecipeIngredients)

  • All Ingredients (default) — all items, sorted by Store Section, then Ingredient Name.
  • Need to Buy — items where Have At Home = No and Purchased = No.
  • Have at Home — items where Have At Home = Yes.

One-Time Entra ID App (to get your Client ID)​

Goal: Create a public client app so Connect-PnPOnline -Interactive works with your tenant.

Before you start​

  • You need Entra ID permissions to register apps and grant admin consent.
  • You will capture two values: Tenant domain (e.g., contoso.onmicrosoft.com) and Application (client) ID (a GUID).

Steps​

  1. Register the app

    • Entra ID → App registrations → New registration
    • Name: PnP Interactive
    • Supported account types: Single tenant
    • Redirect URI: Mobile & desktop applications → http://localhost
    • Click Register, then copy the Application (client) ID (this is your “key”).


  1. Enable public client

    • App → Authentication → Allow public client flows → Yes
    • Ensure http://localhost is present under Mobile & desktop applications.

  1. Add delegated API permissions

    • App → API permissions → Add a permission
    • Microsoft Graph → Delegated → User.Read, openid, offline_access
    • SharePoint → Delegated → AllSites.FullControl
    • Click Grant admin consent for your tenant.

  1. Save your values

    • Tenant domain: e.g., contoso.onmicrosoft.com
    • Client ID (GUID): e.g., 00000000-0000-0000-0000-000000000000

Optional: set a default Client ID (so you don’t type it again)​

[System.Environment]::SetEnvironmentVariable(
  'ENTRAID_CLIENT_ID',
  '00000000-0000-0000-0000-000000000000',  # your Client ID
  [EnvironmentVariableTarget]::User
)
# New shells can now do:
# Connect-PnPOnline -Url $SiteUrl -Tenant $Tenant -Interactive

Common errors & one-line fixes​

  • “Please specify a valid client id” → Add -ClientId <your-guid> to Connect-PnPOnline.
  • “Access denied” → Use an account with Edit/Owner rights on the site.
  • Consent blocked → Ask a Global/Privileged Role Admin to click Grant admin consent.
  • Redirect URI issues → Add http://localhost and Allow public client flows = Yes.

Security notes​

  • This is a public client (no client secret). Do not add or store secrets.
  • If your org enforces Conditional Access, ensure interactive desktop flows are allowed for this app.

Step-by-Step Guide​

Why it matters: PnP.PowerShell targets PowerShell 7+; 5.1 causes errors.

Common error: You ran this in Windows PowerShell 5.1.

Fix (one line): Install and open PowerShell 7 (pwsh), then retry.

Step 2 — Install/Import PnP.PowerShell (Install-Module, Import-Module)​

What it does: Installs and loads the module providing *-PnP* cmdlets.

Why it matters: Needed to connect and manage SharePoint.

Install-Module PnP.PowerShell -Scope CurrentUser -Force
Import-Module PnP.PowerShell -Force

Common prompts: NuGet provider install; trust PSGallery → answer Y.

Common error: Install-Module not recognized.

Fix (one line): Open PowerShell 7 and rerun the commands.

Step 3 — Connect to SharePoint (Connect-PnPOnline)​

What it does: Opens an interactive sign‑in and creates a session.

Why it matters: All provisioning actions run against this site.

Step 4 — Provision Lists (create or update)​

What it does: Creates Recipes and RecipeIngredients if missing.

Why it matters: Lists store your app’s data.

New-PnPList -Title "Recipes" -Template GenericList -OnQuickLaunch -ErrorAction SilentlyContinue
New-PnPList -Title "RecipeIngredients" -Template GenericList -OnQuickLaunch -ErrorAction SilentlyContinue

Fix (one line): This command is safe; it skips if the list exists.

Step 5 — Add Columns (exact internal names and types)$1​

Field Type Syntax Cheatsheet (PnP.PowerShell)​

Use these idempotent patterns to add columns. Replace DisplayName/InternalName/ListTitle and other placeholders.

Tip: To avoid duplicates, wrap each with an existence check (e.g., Get-PnPField -List <List> -Identity <InternalName>). Examples below use XML where needed for full control.

Single line of text

Add-PnPField -List "<ListTitle>" -DisplayName "<DisplayName>" -InternalName "<InternalName>" -Type Text -AddToDefaultView

Multiple lines of text (Plain)

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='Note' Name='<InternalName>' DisplayName='<DisplayName>' NumLines='10' RichText='FALSE' />"

Multiple lines of text (Rich text)

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='Note' Name='<InternalName>' DisplayName='<DisplayName>' NumLines='10' RichText='TRUE' RichTextMode='Compatible' />"

Number

Add-PnPField -List "<ListTitle>" -DisplayName "<DisplayName>" -InternalName "<InternalName>" -Type Number

Currency

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='Currency' Name='<InternalName>' DisplayName='<DisplayName>' Decimals='2' LCID='1033' />"

Yes/No (Boolean)

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='Boolean' Name='<InternalName>' DisplayName='<DisplayName>' Default='0' />"  # 0=No, 1=Yes

Date and Time (Date only)

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='DateTime' Name='<InternalName>' DisplayName='<DisplayName>' Format='DateOnly' FriendlyDisplayFormat='Disabled' />"

Date and Time (Date & Time)

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='DateTime' Name='<InternalName>' DisplayName='<DisplayName>' Format='DateTime' FriendlyDisplayFormat='Disabled' />"

Choice (single-select)

$choices = @('Option A','Option B','Option C')
$xml = "<Field Type='Choice' Name='<InternalName>' DisplayName='<DisplayName>' Format='Dropdown'><CHOICES>" + 
       (($choices | ForEach-Object {"<CHOICE>$_</CHOICE>"}) -join '') + "</CHOICES></Field>"
Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml $xml

Choice (multi-select)

$choices = @('Option A','Option B','Option C')
$xml = "<Field Type='MultiChoice' Name='<InternalName>' DisplayName='<DisplayName>'><CHOICES>" + 
       (($choices | ForEach-Object {"<CHOICE>$_</CHOICE>"}) -join '') + "</CHOICES></Field>"
Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml $xml

Lookup (to another list)

# Target list must exist. Replace list GUID or title in the List attribute; ShowField is the target field to display
$targetList = Get-PnPList -Identity "<TargetListTitle>"
$lx = "<Field Type='Lookup' Name='<InternalName>' DisplayName='<DisplayName>' List='{$($targetList.Id)}' ShowField='Title' RelationshipDeleteBehavior='None' />"
Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml $lx

Lookup (allow multiple)

$targetList = Get-PnPList -Identity "<TargetListTitle>"
$lx = "<Field Type='LookupMulti' Mult='TRUE' Name='<InternalName>' DisplayName='<DisplayName>' List='{$($targetList.Id)}' ShowField='Title' />"
Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml $lx

Person or Group

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='User' Name='<InternalName>' DisplayName='<DisplayName>' UserSelectionMode='PeopleOnly' Mult='FALSE' />"
# People and groups, multi-select:
Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='UserMulti' Name='<InternalNameMulti>' DisplayName='<DisplayNameMulti>' UserSelectionMode='PeopleAndGroups' Mult='TRUE' />"

Hyperlink or Picture

# Hyperlink (URL + Description)
Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='URL' Name='<InternalName>' DisplayName='<DisplayName>' Format='Hyperlink' />"
# Picture (renders image)
Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='URL' Name='<ImgInternal>' DisplayName='<ImgDisplay>' Format='Image' />"

Calculated

# Example: Concatenate two text fields
$fx = "<Field Type='Calculated' ResultType='Text' Name='<InternalName>' DisplayName='<DisplayName>'><Formula>=Title&"" - ""&[QtyDisplay]</Formula><FieldRefs><FieldRef Name='Title'/><FieldRef Name='QtyDisplay'/></FieldRefs></Field>"
Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml $fx

Managed Metadata (Taxonomy)

# Requires an existing Term Set. Use the Group/TermSet IDs from your tenant.
Add-PnPTaxonomyField -List "<ListTitle>" -DisplayName "<DisplayName>" -InternalName "<InternalName>" -TermSetPath "<GroupName>|<TermSetName>" -MultiValue:$false
# Multi-value taxonomy
Add-PnPTaxonomyField -List "<ListTitle>" -DisplayName "<DisplayNameMulti>" -InternalName "<InternalNameMulti>" -TermSetPath "<GroupName>|<TermSetName>" -MultiValue:$true

Location (modern column)

Add-PnPFieldFromXml -List "<ListTitle>" -FieldXml "<Field Type='Location' Name='<InternalName>' DisplayName='<DisplayName>' />"

JSON: mark column required / default value

# Required
Set-PnPField -List "<ListTitle>" -Identity "<InternalName>" -Values @{ Required = $true }
# Default value (Text example)
Set-PnPField -List "<ListTitle>" -Identity "<InternalName>" -Values @{ DefaultValue = 'Default text' }

What it does: Defines helpful list views for shopping.

Why it matters: Users can quickly filter what to buy vs. what they have.

  try { Remove-PnPView -List "RecipeIngredients" -Identity $v -ErrorAction SilentlyContinue } catch {}

# Lists
function Ensure-List { param([string]$ListTitle)
  $list = Get-PnPList -Identity $ListTitle -ErrorAction SilentlyContinue
  if (-not $list) { New-PnPList -Title $ListTitle -Template GenericList -OnQuickLaunch | Out-Null }
}
Ensure-List -ListTitle "Recipes"
Ensure-List -ListTitle "RecipeIngredients"

# Fields helpers
function Ensure-TextField { param($List,$Display,$Internal)
  if (-not (Get-PnPField -List $List -Identity $Internal -ErrorAction SilentlyContinue)) {
    Add-PnPField -List $List -DisplayName $Display -InternalName $Internal -Type Text | Out-Null
  }
}
function Ensure-NoteField { param($List,$Display,$Internal,$Lines=10)
  if (-not (Get-PnPField -List $List -Identity $Internal -ErrorAction SilentlyContinue)) {
    $xml = "<Field Type='Note' Name='$Internal' DisplayName='$Display' NumLines='$Lines' RichText='FALSE' />"
    Add-PnPFieldFromXml -List $List -FieldXml $xml | Out-Null
  }
}
function Ensure-BoolField { param($List,$Display,$Internal)
  if (-not (Get-PnPField -List $List -Identity $Internal -ErrorAction SilentlyContinue)) {
    $xml = "<Field Type='Boolean' Name='$Internal' DisplayName='$Display' Default='0' />"
    Add-PnPFieldFromXml -List $List -FieldXml $xml | Out-Null
  }
}
function Ensure-ChoiceField { param($List,$Display,$Internal,$Choices)
  if (-not (Get-PnPField -List $List -Identity $Internal -ErrorAction SilentlyContinue)) {
    $choicesXml = ($Choices | ForEach-Object {"<CHOICE>$_</CHOICE>"}) -join ''
    $xml = "<Field Type='Choice' Name='$Internal' DisplayName='$Display' Format='Dropdown'><CHOICES>$choicesXml</CHOICES></Field>"
    Add-PnPFieldFromXml -List $List -FieldXml $xml | Out-Null
  }
}
function Ensure-NumberField { param($List,$Display,$Internal)
  if (-not (Get-PnPField -List $List -Identity $Internal -ErrorAction SilentlyContinue)) {
    Add-PnPField -List $List -DisplayName $Display -InternalName $Internal -Type Number | Out-Null
  }
}

function Ensure-List {
  param([string]$ListTitle)

  }

  }

  if (-not (Get-PnPField -List $List -Identity $Internal -ErrorAction SilentlyContinue)) {

function Ensure-NumberField { param($List,$Display,$Internal)

function Ensure-View {
  param(
    [string]$List,
    [string]$Title,
    [string[]]$Fields,
    [string]$CamlQuery,
    [bool]$Default=$false
  )
  try { Remove-PnPView -List $List -Identity $Title -ErrorAction SilentlyContinue } catch {}
  Add-PnPView -List $List -Title $Title -Fields $Fields | Out-Null
  $vals = @{ Query = $CamlQuery }
  if ($Default) { $vals["DefaultView"] = $true }
  Set-PnPView -List $List -Identity $Title -Values $vals | Out-Null
  Write-Host "[View] $List — $Title"
}

Get-PnPList -Identity "Recipes","RecipeIngredients" | Select Title,ItemCount | Format-Table
Write-Host "Provisioning complete." -ForegroundColor Green
